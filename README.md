# Frontend - Angular

Repositório criado com o objetivo de desenvolver projetos utilizando a biblioteca **PO-UI**, da **TOTVS**, para a customização e desenvolvimento de interfaces integradas ao **Protheus**.

Os projetos são desenvolvidos utilizando:

- **Angular**
- **TypeScript**
- **JavaScript**
- **HTML**
- **CSS**
- **PO-UI**

Foco em aprendizagem e utilização de mais recursos referente ao desenvolvimento, fugindo da tradição de (ADVPL x TLPP), os projetos vão ser baseados em problemas já visto e ajustado, porém com a utilização de ferramentas da modalidade.
